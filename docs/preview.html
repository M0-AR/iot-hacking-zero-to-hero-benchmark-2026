🌱 Beginner guide — read this and you are a professional

Let's work this out in a step-by-step way to be sure we have the right answer.

Step 1 — What is IoT hacking?
Smart devices (camera, lock, thermostat, pump) are small computers. Hacking them means checking: can a stranger talk to them, pretend to be them, break them, or steal secrets from them? This repo checks all four, automatically.
Step 2 — Run the proof (3 commands).
git clone <this-repo>
cd iot-hacking-zero-to-hero-benchmark-2026
python3 experiments/run_all.py
Green = you reproduced the book. No soldering, no radio dongles.
Step 3 — Learn one attack per day.
Day 1: passwords (exp04). Day 2: MQTT (exp02). Day 3: Wi-Fi PMKID (exp06). Day 4: RFID/BLE (exp07). Day 5: LoRaWAN (exp05). Each file is <120 lines and explains itself at the top.
Step 4 — Prove it live.
exp02 talks to the public test broker. exp04 checks live firmware releases. exp03 listens for real UPnP replies. You are not trusting screenshots — you are measuring the internet.
